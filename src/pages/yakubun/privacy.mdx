# 訳文 プライバシーポリシー

最終更新日：2026年11月21日

HKDOCS（以下「当方」）は、iPhone・iPad 用のアプリと Safari 機能拡張「訳文」（以下「本アプリ」）における利用者の情報の取り扱いを、次のとおり定めます。

### 1. 収集する情報

本アプリは、利用者のデータを収集しません。アカウントの登録はなく、アクセス解析・広告・トラッキングの仕組みも含みません。

### 2. 翻訳の処理

翻訳は、iPhone・iPad に入っている Apple の翻訳機能を使い、端末の中だけで行います。閲覧中のページの本文と訳文は、当方を含めてどこにも送信せず、保存もしません。

翻訳の言語のダウンロードは、iOS・iPadOS の機能として Apple が提供します。

### 3. 端末の中に保存する情報

- 表示の種類、訳文の大きさ、ボタンをしまったか、「訳」のボタンを出すか、ボタンの位置、訳を隠すかの設定を、Safari 機能拡張の保存領域に保存します。
- 翻訳を続けるため、訳しているページのアドレスを、タブを閉じるまで端末のメモリに置きます。Safari を終えると消えます。

これらの情報は端末の外へ送りません。本アプリを削除すると、保存した設定も消えます。

### 4. Web サイトへのアクセスの許可

本アプリの Safari 機能拡張は、閲覧中のどのページでも訳せるように、「すべての Web サイト」へのアクセスの許可を求めます。ページの内容を読み取るのは、そのページに訳を表示するためだけです。

### 5. 購入とお試し

本アプリのアプリ内課金（「7 日間お試し」と「Pro」）の受け取り・購入・復元と、コードの引き換えは、Apple の App Store が扱います。支払いの情報は Apple が扱い、当方は受け取りません。

本アプリと Safari 機能拡張は、機能を使えるかを決めるために、Apple が端末に持つ購入の記録（お試しを受け取った日時、Pro を持っているか、本アプリを最初に入手した版）を端末の中で読みます。読んだ情報は端末の外へ送らず、保存もしません。

当方が見られるのは、Apple が App Store Connect で提供する売上の件数などの集計だけで、利用者個人を特定する情報は含まれません。

### 6. ポリシーの変更

本ポリシーは、必要に応じて変更することがあります。変更後のポリシーは、本ページへの掲載をもって効力を生じます。
