# 訳文 サポート

「訳文」は、Safari で開いた英語のページに日本語の訳を並べて表示する、iPhone 用の Safari 機能拡張です。翻訳は iPhone の中で行い、ページの本文を外へ送りません。

- 対応：iPhone（iOS 26.4 以降）
- 翻訳：英語 → 日本語
- 表示：行間・段落・単語・全文
- [プライバシーポリシー](/yakubun/privacy/)

### はじめかた

1. 「訳文」のアプリを開き、「言語をダウンロード」で英語と日本語の翻訳の言語を入れます（初回だけ。通信が必要です）。
2. 「Safari の設定を開く」から機能拡張「訳文」をオンにし、「すべての Web サイト」を許可します。
3. Safari で英語のページを開き、左下の「訳」をタップして表示（行間・段落・単語・全文）を選びます。

「終了」を押すと、訳とボタンを消してページを元に戻します。

### よくある質問

#### 言語をダウンロードできません

通信できることを確かめて、アプリの「言語をダウンロード」をもう一度押してください。「この端末では英語 → 日本語の翻訳を使えません」と出る場合は、その端末では使えません。

#### 機能拡張がオンになりません・設定が開きません

iPhone の「設定」→「アプリ」→「Safari」→「機能拡張」→「訳文」を開き、オンにして「すべての Web サイト」を許可してください。

#### 「訳」のボタンが出ません

- 英語でないページには「訳」のボタンを出しません。
- 機能拡張をオンにした直後は、ページを再読み込みしてください。
- Safari のアドレスバーの機能拡張のメニューで、そのサイトへのアクセスが許可されているかを確かめてください。

#### 訳されない部分があります

ナビゲーション・コード・入力欄は、意図して訳しません。ページの作りによっては、本文の一部を訳せないことがあります。

#### 訳が不自然です

訳は iPhone の翻訳機能によるもので、文脈によっては不自然になることがあります。

#### 通信なしで使えますか

言語をダウンロードした後は、翻訳そのものに通信は要りません。読み込み済みのページなら、機内モードでも訳せます。
