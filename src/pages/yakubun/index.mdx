# 訳文 サポート

「訳文」は、Safari で開いた英語のページに日本語の訳を並べて表示する、iPhone・iPad 用の Safari 機能拡張です。翻訳は端末の中で行い、ページの本文を外へ送りません。

<a href="https://apps.apple.com/jp/app/apple-store/id6827465815?pt=129688386&mt=8&ct=hkdocs-support"><img src="/img/yakubun-app-store-badge-ja.svg" alt="App Store からダウンロード" height="40" /></a>

- 対応：iPhone（iOS 26.4 以降）・iPad（iPadOS 26.4 以降）
- 翻訳：英語 → 日本語
- 表示：行間・段落・単語・全文
- 料金：7 日間無料でお試しでき、その後も使うには Pro（買い切り）の購入が必要です。版 1.1 より前に入れた方は、購入しなくてもすべて使えます。
- [プライバシーポリシー](/yakubun/privacy/)

### はじめかた

1. 「訳文」のアプリを開き、「言語をダウンロード」で英語と日本語の翻訳の言語を入れます（初回だけ。通信が必要です）。
2. 「Safari の設定を開く」から機能拡張「訳文」をオンにし、「すべての Web サイト」を許可します。
3. アプリの「お試しを始める」で、7 日間のお試しを受け取ります。
4. Safari で英語のページを開き、左下の「訳」をタップして表示（行間・段落・単語・全文）を選びます。

「終了」を押すと、訳とボタンを消してページを元に戻します。

### よくある質問

#### 言語をダウンロードできません

通信できることを確かめて、アプリの「言語をダウンロード」をもう一度押してください。「この端末では英語 → 日本語の翻訳を使えません」と出る場合は、その端末では使えません。

#### 機能拡張がオンになりません・設定が開きません

iPhone・iPad の「設定」→「アプリ」→「Safari」→「機能拡張」→「訳文」を開き、オンにして「すべての Web サイト」を許可してください。

#### 「タップしてアプリ「訳文」を開き、「はじめに」を済ませてください」と出ます

お試しを受け取る前です。知らせをタップしてアプリを開き、「はじめに」の「お試しを始める」でお試しを受け取るか、Pro を購入してください。

#### 「お試しの期間が終わりました」と出ます

お試しは受け取ってから 7 日で終わり、すべての表示が止まります。続けて使うには、知らせをタップしてアプリを開き、Pro を購入してください。

#### 機種変更や入れ直しの後に Pro が使えません

アプリの「はじめに」の「購入を復元」を押してください。Pro を購入した Apple アカウントでサインインしていれば戻ります。お試しは、入れ直しても始まり直りません。

#### 前の版から使っています。購入が必要ですか

版 1.1 より前に入れた方は、購入しなくてもこれまでどおりすべての表示を使えます。アプリの「はじめに」に「前の版から使っている方は、購入しなくてもすべての表示を使えます」と出ます。

#### 「訳」のボタンが出ません

- 英語でないページには「訳」のボタンを出しません。
- 機能拡張をオンにした直後は、ページを再読み込みしてください。
- Safari のアドレスバーの機能拡張のメニューで、そのサイトへのアクセスが許可されているかを確かめてください。
- 版 1.0.1 以降は、Safari のアドレスバーの左端のボタンから「訳文」を開き、「「訳」のボタンを出す」がオンかを確かめてください。

#### ボタンが消えました

版 1.0.1 以降は、「訳」とボタンを画面の横の外へスワイプすると、端にしまえます。残ったつまみをタップすると戻ります。

#### 訳されない部分があります

ナビゲーション・コード・入力欄は、意図して訳しません。ページの作りによっては、本文の一部を訳せないことがあります。

#### 訳が不自然です

訳は端末の翻訳機能によるもので、文脈によっては不自然になることがあります。

#### 通信なしで使えますか

言語をダウンロードした後は、翻訳そのものに通信は要りません。読み込み済みのページなら、機内モードでも訳せます。
