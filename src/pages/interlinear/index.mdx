# Interlinear サポート

「Interlinear」は、Safari で開いたページに、選んだ言語の訳を並べて表示する、iPhone・iPad 用の Safari 機能拡張です。翻訳は端末の中で行い、ページの本文を外へ送りません。

- 対応：iPhone（iOS 26.4 以降）・iPad（iPadOS 26.4 以降）
- 言語：英語・日本語・韓国語・中国語（簡体）・中国語（繁体）・スペイン語・ポルトガル語（ブラジル）・フランス語・ドイツ語・イタリア語・ロシア語・トルコ語・ポーランド語・ベトナム語・インドネシア語・タイ語の、どの組でも訳します。
- 表示：行間・段落・単語（英語のページだけ）・全文
- 料金：7 日間無料でお試しでき、その後も使うには Pro（買い切り）の購入が必要です。
- [プライバシーポリシー](/interlinear/privacy/)

### はじめかた

1. 「Interlinear」のアプリを開き、「言語を選ぶ」で翻訳先と訳す元の言語を選びます。選ぶと、その言語の翻訳のデータをダウンロードします（通信が必要です）。
2. 「Safari の設定を開く」から機能拡張「Interlinear」をオンにし、「すべての Web サイト」を許可します。
3. アプリの「お試しを始める」で、7 日間のお試しを受け取ります。
4. Safari で選んだ言語のページを開き、左下の丸いボタン（「訳」）をタップして表示（行間・段落・単語・全文）を選びます。

「終了」を押すと、訳とボタンを消してページを元に戻します。

### よくある質問

#### 言語をダウンロードできません

通信できることを確かめて、アプリの言語の画面の「ダウンロード」をもう一度押してください。ダウンロードはバックグラウンドで続きます。言語に「使えません」と出る場合は、その端末ではその言語を訳せません。

#### 翻訳先や訳す元の言語を変えたい

アプリの「はじめに」の「言語を選ぶ」を開くと、いつでも変えられます。翻訳先を変えると、訳す元の言語のデータを入れ直します。

#### 機能拡張がオンになりません・設定が開きません

iPhone・iPad の「設定」→「アプリ」→「Safari」→「機能拡張」→「Interlinear」を開き、オンにして「すべての Web サイト」を許可してください。

#### 「翻訳の言語が未ダウンロードです」と出ます

そのページの言語と翻訳先の組のデータが、まだ入っていません。知らせをタップしてアプリを開き、言語の画面でダウンロードしてください。

#### 「タップしてアプリ「Interlinear」を開き、「はじめに」を済ませてください」と出ます

お試しを受け取る前です。知らせをタップしてアプリを開き、「はじめに」の「お試しを始める」でお試しを受け取るか、Pro を購入してください。

#### 「お試しの期間が終わりました」と出ます

お試しは受け取ってから 7 日で終わり、すべての表示が止まります。続けて使うには、知らせをタップしてアプリを開き、Pro を購入してください。

#### 機種変更や入れ直しの後に Pro が使えません

アプリの「はじめに」の「購入を復元」を押してください。Pro を購入した Apple アカウントでサインインしていれば戻ります。お試しは、入れ直しても始まり直りません。

#### 「訳」のボタンが出ません

- 「訳す元」に選んだ言語のページにだけボタンを出します。翻訳先と同じ言語のページにも出しません。
- 機能拡張をオンにした直後は、ページを再読み込みしてください。
- Safari のアドレスバーの機能拡張のメニューで、そのサイトへのアクセスが許可されているかを確かめてください。
- Safari のアドレスバーの左端のボタンから「Interlinear」を開き、「「訳」のボタンを出す」がオンかを確かめてください。

#### 「単語」が押せません

「単語」は、今は英語のページだけで使えます。ほかの言語のページでは、行間・段落・全文をお使いください。

#### ボタンが消えました

ボタンを画面の横の外へスワイプすると、端にしまえます。残ったつまみをタップすると戻ります。

#### 訳されない部分があります

ナビゲーション・コード・入力欄は、意図して訳しません。訳す元に選んでいない言語の段落と、翻訳先と同じ言語の段落も訳しません。ページの作りによっては、本文の一部を訳せないことがあります。

#### 訳が不自然です

訳は端末の翻訳機能によるもので、文脈や言語の組によっては不自然になることがあります。

#### 通信なしで使えますか

言語をダウンロードした後は、翻訳そのものに通信は要りません。読み込み済みのページなら、機内モードでも訳せます。

#### 「訳文」とは何が違いますか

日本の App Store にある[「訳文」](/yakubun/)は、英語 → 日本語だけを訳すアプリで、利用の統計も送りません。Interlinear は 16 の言語のどの組でも訳します。別のアプリなので、購入もそれぞれに必要です。
