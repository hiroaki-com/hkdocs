# Yakubun Privacy Policy

Last updated: November 3, 2026

HKDOCS ("we") sets out below how user information is handled in Yakubun (訳文), an iPhone app and Safari extension (the "App").

### 1. Information we collect

The App does not collect user data. There is no account registration, and the App contains no analytics, advertising, or tracking.

### 2. Translation processing

Translation uses Apple's translation feature built into the iPhone and runs only on the device. The text of the page being viewed and its translation are never sent anywhere, including to us, and are never stored.

The download of translation languages is provided by Apple as a feature of iOS.

### 3. Information stored on the device

- Settings for the view, the size of the translated text, whether the button is tucked away, and whether to show the "訳" button are stored in the Safari extension's storage area.
- To keep translating, the address of the page being translated is held in the device's memory until the tab is closed. It is cleared when Safari is quit.

This information is never sent off the device. Deleting the App also deletes the saved settings.

### 4. Permission to access websites

The App's Safari extension requests access to "All Websites" so that it can translate whichever page is being viewed. It reads page content only to display the translation on that page.

### 5. Changes to this policy

We may change this policy as needed. The revised policy takes effect when it is posted on this page.
